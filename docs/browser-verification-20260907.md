# 실제 브라우저 확인 — 2026-09-07

Codex 내장 브라우저, macOS, 로컬 정적 서버(1280×720)에서 실제 WebGL과 UI를 확인했습니다. 배포된 GitHub Pages의 검증이 아닙니다. 버튼·구 선택과 실제 화면만 사용했고 숨은 비행 상태를 변경하지 않았습니다.

## 확인 결과

- 초기 압축 지형·건물 작업자·랜드마크 로딩 후 시작 버튼이 활성화되고 실제 3D 건물과 지형이 표시됐습니다.
- 25개 구 각각에서 선택 → 이동 → 일시정지 → HUD 상세도 N/N 완료를 확인했습니다. 빠른 동서남북 전환에서도 실패 표시는 없었으며 console error/warn은0건이었습니다.
- 작업자 예외 처리 수정 후 새로고침하고 25구 전체를 다시 검사했습니다. 아래는 최종 반복의 관찰값이며 날아가는 시간과 LOD 회수 여유 때문에 이후 값은 달라질 수 있습니다. N은 표시 상세도 그룹 수이지 원본 건물 수나 모든 건물이 보인다는 뜻이 아닙니다.
- 강서구와 강동구에서 미니맵 위치·3D 도시/산/물 장면을 시각 확인했습니다. HUD와 설명의 겹침을 수정하고 높이 추정 범례가 보이는 것도 확인했습니다.
- 같은 위치 일시정지/재개와 서로 먼 구역 이동을 확인했습니다. 모든 랜드마크를 사람이 직접 비행해 완주한 검증은 아닙니다.

## 별도 CPU 검증과 남은 한계

`npm test` 58개, `npm run test:full-city` 657청크·366,746형상·4,754,660삼각형 검사, 기존204GLB 회귀 검사, 정적 build를 통과했습니다. 작업자 timeout/부착/정리 실패, 오래된 요청, bfcache의 worker 보존은 CPU 회귀 테스트이며 실제 브라우저에 장애를 주입한 검증은 아닙니다.

실측 높이·현재 외관·전역 도로와 교량·수직 기준의 정확성, 36.5만 동 각각의 시각 대조, 모든 LOD 전환 품질, 실제 모바일 멀티터치, 프레임률/장시간 GPU 메모리는 검증 완료로 주장하지 않습니다. [데이터 범위·추정·라이선스](full-seoul-data.md)의 제한은 이 브라우저 검증 후에도 그대로입니다. Sites 사용·병합·웹 배포는 수행하지 않았습니다.
