# 서울 전역 재구성 — 자료 확보와 완료 조건

2026-09-07 조사. **서울 전역 재구성은 아직 구현되지 않았습니다.** 이 문서는 자료 선택·권리·정확도 조건이며, 작업 완료 보고가 아닙니다.

## 현재 모델이 요구 수준에 못 미치는 부분

- 실제 자료 bbox는 W126.92/E127.11/S37.50/N37.59, 약16.8 × 10.0km입니다. 이 사각형 면적을 서울 행정구역 커버리지 비율로 환산하지 않습니다. 서부·북부·남부·동부 외곽의 상당 부분이 없습니다.
- 다섯 랜드마크만 별도 Blender 참고 모델입니다. 일반 건물69,716동은 OSM 외곽선과 출처 구분을 잃은 추정 높이, 반복 외장입니다. 경복궁도 근정전 중심 모델이지 궁궐 전체가 아닙니다.
- 지형은 과거 SRTM/GMTED 합성자료이며, 수면은 지형에 맞춘 표시입니다. 현행 지반·수위·항공 안전 자료가 아닙니다.
- 지도 범위만 늘리면 투영 원점·축척이 달라지고 과거 지도를 늘려 그리게 됩니다. `scene-contract.mjs`는 이런 잘못된 조합을 시작 전에 거부합니다. 새 데이터나 정확도가 추가되는 기능은 아닙니다.

## 실제 외관을 위한 공식 3D 경로

### VWorld WebGL 3D

[국토교통부 공식 API 안내](https://www.data.go.kr/data/3073144/openapi.do)는 대한민국을 대상으로 하는 WebGL/Cesium 기반 3D 지도와 회원가입 후 인증키 발급 절차를 설명합니다. 원본 모델을 익명으로 대량 추출해 저장소에 재배포하는 방식과 공식 API를 통해 표시하는 방식은 구분합니다.

필요한 입력은 사용자의 VWorld 계정에서 설정한 **서비스 도메인용 인증키**입니다. 키를 README, Git, PR 또는 채팅에 붙이지 않습니다. 연결 시 실제 허용 도메인·쿼터·약관을 확인하고, 필요한 설정만 사용자 기기에 둡니다. 다른 서비스에서 수집한 키나 공개 예제의 교육용 키를 사용하지 않습니다.

이 경로가 현재의 반복 외장 모델보다 요청에 맞는 후보이지만, API 가입만으로 서울의 모든 건물에 최신 실사 외관·실측 높이가 있다는 보장은 없습니다. 연결 후 지역별 3D 제공 범위, 촬영·제작 시점, 누락과 고도 기준을 실제로 검사해야 합니다. 현재 앱에 연결되거나 검증된 상태가 아닙니다.

### 서울시 S-Map

[서울시 공식 설명](https://english.seoul.go.kr/policy/smart-city/spatial-data/)은 서울605.23km², 건축물 약60만동과 시설·지형, 실사·정밀 모델을 안내합니다. 이는 서울시 서비스의 설명이지 이 저장소가 가진 데이터량이 아닙니다.

조사 범위에서는 이 게임에 넣을 raw GLB/3D Tiles의 공개 다운로드·변환·재배포 권한을 확인하지 못했습니다. 공개 뷰어를 볼 수 있다는 이유로 모델을 추출하거나 복제하지 않습니다. 공식 API/공급·사용 허가가 확보되면 자료 후보로 다시 검토합니다.

## 건물 위치·높이의 공식 파일 경로

[공식 컬럼 정의서 · 2026-01-02](<https://www.vworld.kr/contents/국가중점데이터_컬럼정의서(26.01.02)_배포용.xlsx>)의 `AL_D010` 정의를 참고했습니다. 원본 서울 파일은 아직 확보하지 않았습니다.

[일별GIS건물통합정보 — 공공데이터포털](https://www.data.go.kr/data/15052097/fileData.do)은 연속수치지도 건물 공간정보와 세움터 건축물대장 속성을 결합한 SHP 자료입니다. [VWorld 서울 전체 파일](https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=NA&dsId=18&sidoCd=11&fileGbnCd=AL)에서 서울특별시·전체자료를 선택합니다. 조사 시 표시: SHP129MB, EPSG:5186, 데이터 기준2026-08-09, 갱신2026-08-24. 실제 파일은 아직 내려받지 않았고 다운로드에는 로그인이 필요했습니다.

공식 컬럼정의의 `AL_D010`은 `A1` GIS건물통합식별번호, `A16` 높이(m), `A22` 데이터기준일자, `A24` 건물명, `A25` 건물동명, `A26` 지상층 수, `A27` 지하층 수를 정의합니다. 실제 제공 파일의 스키마와 값은 받은 뒤 다시 확인해야 합니다. 필수 컬럼이라는 표시도 null·0·잘못된 높이나 공간 매칭 오류가 없다는 증명이 아닙니다. SHP에는 실사 외관 텍스처가 포함된다고 확인하지 않았습니다.

**재배포 조건 확인 필요:** 공공데이터포털은 이용 제한 없음으로 표시하지만, 조사 시 VWorld 페이지의 CC BY 배지·설명과 라이선스 바로가기의 `by-nc-nd/2.0/kr` 대상이 서로 달랐습니다. 변환 GLB 공개·재배포 전에 제공기관의 명확한 조건 또는 해당 파일의 라이선스를 확보해야 합니다. 이름이 비슷한 다른 “건물통합정보 구축관리” 데이터의 조건을 대신 적용하지 않습니다.

파일 경로로 진행한다면 서울 전체 ZIP의 `.shp`, `.shx`, `.dbf`, `.prj`와 동봉 라이선스·메타데이터가 필요합니다. 사용자 다운로드 파일을 받아 지역 코드·범위·해시·인코딩·높이 결측·중복·갱신일을 검사한 뒤 변환합니다. 개인정보 성격의 대장 속성은 게임에 필요하지 않으며 공개 산출물에서 제외합니다.

## 키 없이 가능한 공개 대안과 한계

[Overture Buildings](https://docs.overturemaps.org/schema/reference/buildings/building/)는 공개 건물 외곽선과 선택적 높이·층수·부분 형상을 제공합니다. 계정 없이 공개 릴리스를 지역 범위로 가져올 수 있지만, 누락 높이를 채운 모델은 추정입니다. 건물 외곽선 전역 커버리지와 서울 실사 복원을 같은 결과로 표시하지 않습니다.

[GlobalBuildingAtlas 공식 저장소](https://github.com/zhu-xlab/GlobalBuildingAtlas)는 높이·LoD1 후보지만 자료별 라이선스가 다릅니다. 조사 시 ODbLPolygon은 ODbL, 나머지 Polygon·Height·LoD1은 CC BY-NC 조건이며, WFS 자동 추출·대량 다운로드는 공식 문서에서 금지했습니다. 이를 무조건 자유로운 실사3D 원본으로 취급하거나 WFS 제한을 우회하지 않습니다.

## 전역 구현의 검증 기준

1. 서울 행정경계 전체와25개 자치구별 포함·누락 수를 확인합니다. bbox만 크게 바꾸거나 샘플 몇 곳만 추가하는 것으로 대체하지 않습니다.
2. 건물별 외곽선·중정·부분 형상·지붕과 원본 식별자를 보존합니다. 직접 높이, 대장 높이, 층수 추정, 결측 대체를 각각 기록하며 알려진 높이를 임의로380m 이하로 자르지 않습니다.
3. 지형·수면·건물·지도·랜드마크의 수평좌표와 수직기준을 통일합니다. 새 영역 전체의 지형을 확보하고 기존257² 지형을 늘려 쓰지 않습니다.
4. 지형·지도·건물을 거리/상세도별로 타일화합니다. 전국 또는 서울 전체 원본을 시작 시 모두 다운로드하지 않습니다. 로딩 중 빈 구역, 타일 경계·출현, 실패·재시도, GPU 자원 회수를 확인합니다.
5. 도심뿐 아니라 강서·은평·도봉·노원·강동·금천·서초 등의 대표 지점과 산·섬·다리를 비교합니다. 미제공 구역·과거 촬영·추정 외관을 숨기지 않습니다.
6. 허락된 브라우저 테스트에서 실제 화면·비행·모바일 조작을 검증합니다. CPU 검사·파일 개수·Blender 단독 렌더만으로 서울 전체 정확도를 승인하지 않습니다.

현재 필요한 결정: 공식 VWorld 3D 연결을 위한 계정/도메인 설정, 또는 합법적으로 사용할 수 있는 전역 원본 자료 제공. 인증키·원본·권리 조건이 없는 상태에서 전역 실사 모델을 완료했다고 표시하지 않습니다.
