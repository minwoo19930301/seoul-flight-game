# Landmark modules

One ES module per landmark (`landmarks/<id>.mjs`). `landmarks/index.mjs` is generated by
`node scripts/generate-landmark-stubs.mjs --index` and imported by `seoul-flight.mjs`.

## Module contract

```js
import * as THREE from "../vendor/three.module.js";
import { M, box, cyl, hipRoof, hanokHall, /* ... */ } from "./_helpers.mjs";

export default {
  id: "jongno-tower",            // must equal the file name
  name: "종로타워",               // Korean label shown in the HUD and on the map
  nameEn: "Jongno Tower",
  district: "종로구",             // one of the 25 Seoul districts
  lat: 37.5704, lon: 126.9830,   // WGS84 position of the model origin (do not change)
  height: 132,                   // top of the model above ground, in units (≈ metres). Must match the geometry within 15 %.
  colliderRadius: 30,            // horizontal radius (from origin) that contains every vertex. Real buildings within it are removed.
  detail: "high",                // "high" | "medium" | "low" - triangle budgets 60k / 30k / 15k
  description: "상부가 떠 있는 탑클라우드 링 구조의 33층 오피스",
  create() {                     // called once; ground is y = 0 (the viewer lifts the group to terrain height)
    const g = new THREE.Group();
    // ... add meshes ...
    return g;
  },
};
```

## Rules

- **Scale**: 1 unit ≈ 1 m vertically; use roughly the same scale for footprints so proportions match the
  real building. Keep the whole model inside `colliderRadius` (the validator checks this).
- **Orientation**: +x = east, −z = north (i.e. `z` grows towards the south). Rotate with `ry` (radians).
- **Ground** is `y = 0`. Nothing may go lower than `y = -3`. Do not lift the model by a "terrain height".
- **Only geometry + `MeshStandardMaterial`** (use the shared palette `M` or `material(color, options)`).
  No canvases, textures, images, DOM, `fetch`, timers or animation - modules also run headless in Node.
- **Budget**: stay under the triangle budget for your `detail` level; avoid `SphereGeometry`/`CylinderGeometry`
  with very high segment counts, and avoid thousands of tiny meshes (meshes are merged per material at load,
  but each mesh still costs build time).
- **Faithfulness beats decoration**: get the massing, proportions, colours, roof shape and the one or two
  features people recognise the building by (e.g. 종로타워's floating ring, 국회의사당's green dome,
  63빌딩's gold glass, DDP's silver blob). Study reference photos / floor counts / footprint dimensions.
- Do not edit other landmark files, `_helpers.mjs`, or the viewer.

## Helpers (`_helpers.mjs`)

All primitives are **bottom-anchored** (`y` = base) and are added to the group you pass as the first argument.

| helper | purpose |
| --- | --- |
| `box(g, {w,h,d,x,y,z,mat,ry})` | rectangular block |
| `cyl(g, {rTop,rBot,h,x,y,z,mat,seg,ry,sx,sz})` | cylinder / cone frustum (`seg: 4` = square shaft) |
| `cone(g, {r,h,...})`, `sphere(g, {r,...})`, `dome(g, {r,scaleY,theta,...})` | rounded forms |
| `frustum(g, {wBot,dBot,wTop,dTop,h,...})` | tapered rectangular tower segment |
| `prism(g, {points:[[x,z],...],h,holes,...})` | extruded custom footprint (L/U/cross shapes, courtyards) |
| `polygonPrism(g, {sides,r,h,...})` | octagon/hexagon towers and pavilions |
| `ring(g, {r,tube,...})`, `disc(g, {r,rInner,...})` | torus ring / flat annulus |
| `lathe(g, {profile:[[r,y],...],...})` | revolved profile (tower shafts, domes, spires) |
| `strut(g, {from:[x,y,z],to:[x,y,z],r,mat})` | diagonal member / cable / mast |
| `archBlock(g, {w,h,d,archW,archH,...})` | wall block with an arched opening (gates) |
| `hipRoof(g, {w,d,h,overhang,ridge,curve,mat,ry})` | Korean tiled hip roof with lifted eaves |
| `gableRoof`, `pyramidRoof` | other roof forms |
| `hanokHall(g, {w,d,stories,wallH,roofH,platformH,...})` | complete traditional hall (platform, columns, walls, beam band, roof); returns total height |
| `hanokWall(g, {length,...})`, `stonePagoda(g, {tiers,baseW,...})` | palace wall segment, stone pagoda |
| `tower(g, {w,d,h,mat,floorHeight,...})`, `roundTower(g, {r,h,...})` | office tower with floor bands |
| `floorBands`, `mullions` | facade articulation |
| `tree`, `treePatch`, `slab`, `subgroup`, `polar`, `deg`, `seededRandom` | utilities |

## Validate

```bash
node scripts/validate-landmarks.mjs landmarks/<id>.mjs   # one file
node scripts/validate-landmarks.mjs                       # everything + district coverage + overlap check
```

The validator reports the measured model height and radius; update `height` / `colliderRadius` to match.
